# FORGECRAFT — 3D Character Studio

A browser-based fantasy character customization prototype built with HTML, CSS, JavaScript, and Three.js.

## Run it
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr, so internet access is required.

## Features
- Interactive 3D viewport with orbit and zoom
- Stylized procedural Human, Elf, and Orc characters
- Skin, hair, armor, and trim colors
- Armor, shoulder plates, cape, headgear, and weapons
- Arcane glow and studio backgrounds
- Randomize character and save builds in browser local storage
- Export a PNG preview

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch `main` and folder `/(root)`, then save.
4. Wait for GitHub Pages to finish deploying.

## Prototype limitations
This is an early prototype using basic procedural shapes, not a production replacement for Hero Forge. It does not yet support detailed sculpted assets, full pose editing, or 3D-printable STL export.
